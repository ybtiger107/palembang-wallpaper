# Changelog

## 0.1.0 — 2026-09-29

First public release of Palembang Wallpaper, including:

- Live solar-cycle mode
- Pulse mode
- Automatic, City, and Custom location sources
- Native fullscreen and resizable macOS rendering
- Smooth palette transitions
- Native macOS menus and Settings
- Local-only privacy model
- PalembangSwiftUI 0.8.0 integration
